# CodeAlpha_AIChatBot
A professional Java-based AI ChatBot with an interactive GUI interface using Swing. This chatbot uses basic NLP techniques and rule-based responses to answer questions related to Java, OOP, AI, Internship, College, Time, Date, and Machine Learning. Designed with a modern user-friendly interface and real-time interaction features.
# AI ChatBot - Java GUI Project

## Description
This project is a Java-based AI ChatBot developed using Java Swing GUI.

The chatbot can answer basic questions related to:
- Java
- OOP
- AI
- Internship
- College
- Time
- Date
- Machine Learning

## Features
- Interactive GUI Interface
- Real-time chatbot responses
- NLP-based keyword matching
- Attractive chatbot window
- Clear chat feature
- Date and time support

## Technologies Used
- Java
- Swing
- OOP Concepts

## How to Run

Compile:
```bash
javac AIChatBotGUI.java
```
Run:
```bash
java AIChatBotGUI
```
